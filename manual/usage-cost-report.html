5. Scope and limitations

  • Only this PC's available Codex project records are counted. Claude usage and records held only on other PCs are excluded.
  • API cache-write charges cannot be reconstructed from these counters and are excluded, along with paid tools, taxes and subscription charges.
  • Standard short-context prices are assumed. Model choice, Fast mode, longer requests, caching and future price changes can change an API bill.
  • Actual money paid cannot be determined from these token records. All currency amounts here are in US dollars.
